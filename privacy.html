CJ eBay Robot · Private seller integration

Privacy Policy

Effective date: 15 October 2026

1. Operator and scope

CJ eBay Robot is operated by Vilius Budginas, Lithuania. Contact: everythinglandstore@gmail.com. This policy covers this application's eBay integration, API testing and account-deletion notification receiver. The application is currently being configured for the operator's own eBay seller account; it is not a public registration service.

2. Information processed

The notification receiver processes eBay account-deletion messages, which can contain an eBay user ID, username, public user ID, notification ID and event timestamps. It stores the verified message, signature and processing status in a private Cloudflare D1 database. Application credentials are configured in Cloudflare Workers secrets; temporary application access tokens and public verification keys are cached in worker memory.

When the seller authorizes API inspection, the categories retrieved depend on the API calls actually made: account identifiers and settings, listing and inventory information, sales and performance reports, and, only when order endpoints are used, order details and buyer contact or delivery information. Granting an OAuth permission does not itself download those records. eBay handles account passwords on its own sign-in pages; this application does not request your eBay password.

3. Purposes and grounds

Information is used only to connect and test the authorized seller account, support its marketplace operations, protect the integration, and act on eBay account-deletion notifications. Applicable grounds include providing requested services, legitimate interests in secure operation and troubleshooting, and compliance with applicable obligations. OAuth authorization controls API access; it is not a substitute for an applicable legal basis for processing buyer information.

4. Recipients and infrastructure

eBay provides the API and authentication services. Cloudflare provides the public endpoint, execution, database and operational logging infrastructure. Its processing may involve locations outside Lithuania or the EEA under its applicable service terms and transfer arrangements. Authorized local inspection tools run on the operator's computer. Application data is not sold, rented or used for unrelated advertising.

The current testing setup does not send buyer information to CJdropshipping. Before supplier fulfillment or additional data recipients are enabled, this policy and the associated handling arrangements will be updated to describe those transfers.

5. Retention and deletion

Records are kept only for the purposes above and reviewed for removal when no longer needed. Deletion notifications remain pending until the operator or a connected processor has checked and removed the affected application data. The receiver currently records notifications; it does not itself erase data in other systems. The operator must complete that follow-up and remove unnecessary notification payloads. Any legally required retention is limited to the records and period required by the applicable obligation.

Seller access can be revoked through eBay. Revocation stops future authorized access but does not itself erase existing copies. Contact the operator to request review or deletion of those copies.

6. Security and logs

Access to the application configuration and database is restricted to authorized administration. The public connection uses HTTPS. Notification signatures are checked before messages are stored. Application-generated error diagnostics use predefined codes and source positions rather than raw payloads or credentials. Cloudflare may separately process request metadata and operational logs, including IP addresses and request information, for delivery, security and troubleshooting. No advertising analytics or application tracking cookies are added to this policy page.

7. Your requests and choices

Contact everythinglandstore@gmail.com to request access, correction, deletion, restriction, portability or to object to processing where applicable. Identity may need to be verified. Requests are assessed under applicable law, normally within one month. You may complain to Lithuania's State Data Protection Inspectorate or another competent supervisory authority. Requests about eBay's own records should also be directed to eBay.

8. Changes

This policy will be updated as the integration changes. The effective date above identifies the published version. Material changes affecting personal-data use will be communicated to affected users as appropriate.
